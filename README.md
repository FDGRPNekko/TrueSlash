## ⚡ Основные возможности

### 🔐 Протоколы и сетевое ядро

TrueSlash использует **Xray-core** и поддерживает широкий набор современных протоколов и транспортов.

- **VLESS** - Reality, XHTTP, TCP, WebSocket, gRPC и другие транспорты.
- **VMess** - поддержка существующих конфигураций.
- **Trojan** - защищённые соединения с использованием TLS.
- **Shadowsocks** - лёгкий и производительный протокол.
- **Hysteria2** - высокопроизводительные соединения на базе QUIC.
- **olcRTC** - дополнительный протокол подключения.
- **Xray JSON** - импорт и редактирование расширенных конфигураций.

Используется ядро Xray с поддержкой современных сетевых технологий.

### 🌍 Умное подключение и проверка серверов

TrueSlash не ограничивается проверкой открытого TCP-порта. Приложение выполняет реальные URL-запросы через VPN-сервер, позволяя точнее определить его работоспособность.

- Реальный URL-пинг вместо TCP-проверки.
- Отображение задержки в миллисекундах.
- Цветовая индикация качества соединения.
- Проверка всех серверов одной кнопкой.
- Исправленная обработка таймаутов и недоступных серверов.
- Проверка JSON-конфигураций и групп серверов.
- Автоматический выбор доступного сервера.
- Переключение на резервный сервер при отказе основного.
- Перепроверка серверов без принудительного разрыва действующих соединений.

### 🛡️ Безопасность и маршрутизация

- **Kill Switch** - защита при потере VPN-соединения.
- **TUN** - маршрутизация системного трафика через VPN.
- **System Proxy** - подключение через системный прокси.
- **Раздельная маршрутизация** - настройка правил для приложений и направлений трафика.
- **TCP Fragmentation** - параметры `tlshello`, `packets`, `length`, `interval`, `noise`.
- **Mux** - мультиплексирование соединений.
- **Автоподключение** - автоматическое восстановление VPN.
- **Режимы для разных сетей** - отдельные настройки для Wi-Fi и мобильного интернета.
- **Режим модема (root)** - раздача VPN-подключения на другие устройства, включая Samsung.

*Набор доступных функций зависит от операционной системы.*

## 🔄 Подписки и Remnawave

TrueSlash предоставляет расширенную поддержку подписок Remnawave, включая JSON-конфигурации, автоматическую балансировку и дополнительные метаданные серверов.

### 📋 Управление подписками

- Добавление подписок по URL.
- Импорт из буфера обмена и по QR-коду.
- Поддержка ссылок `trsl://import/...`.
- Автоматическое обновление подписок в фоне.
- Обновление при запуске приложения.
- Отображение названия подписки через `profile-title`.
- Информация об оставшемся трафике.
- Срок действия в формате «Осталось N дней · Действует до».
- Отображение времени последнего обновления.
- Изменение порядка подписок.
- Сворачивание групп серверов.
- Блокировка положения списка.

### 📝 Описания серверов

Поддерживается поле `serverDescription`.

Вместо стандартного технического названия вида `VLESS | XHTTP | Reality` отображается описание, заданное администратором подписки.

### 📂 Разделители серверов

Специальные служебные узлы `select-server.com` и `select-server.ru` преобразуются в визуальные разделители.

Это позволяет группировать серверы по странам, назначению или другим категориям.

### 📢 Объявления подписки

Поддерживается поле `announce`.

- Краткий текст объявления на главном экране.
- Плавное затухание длинного текста.
- Просмотр полного объявления по нажатию.
- Кнопка перехода на страницу подписки.
- Кнопка обращения в поддержку.

Поддерживаемые заголовки:

- `support-url`
- `profile-web-page-url`
- `profile-title`

### ⚖️ Автоматический балансировщик

TrueSlash поддерживает автоматический выбор серверов из шаблонов Remnawave.

- Выбор доступного сервера.
- Переключение при отказе узла.
- Проверка состояния серверов.
- Работа с группами JSON-конфигураций.
- Сохранение действующих соединений при перепроверке.
